# 个人主页

技术影响力导向的个人站：文章是主角，项目是可信度证据。

## 跑起来

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # 产物在 dist/，纯静态
```

## 设计原则

**交互逻辑参考苹果，长相是自己的。** 参考的是这几条，不是配色：

| 原则 | 落在哪 |
| --- | --- |
| 一屏一件事 | 首页每个 `.screen` 只讲一件事，精选一屏一篇，不做卡片网格 |
| 滚动即叙事 | 首页顺序固定：我是谁 → 发现了什么 → 造了什么 → 订阅 |
| 先给结论 | 每篇文章顶部先给一句话结论，细节和复现步骤在下面 |
| 动效必须表意 | 淡入只用在首页叙事屏；归档页和正文页不做淡入，因为那里的动效不携带信息 |
| 共享元素过渡 | 列表标题原地放大成正文标题，靠 `transition:name={t-<id>}` |
| 内容即界面 | 向下读时导航收起，向上找时回来；正文列宽锁死 |
| 即时反馈 | 悬停即预取；按下即有反应，不等松手 |
| 每屏一个出口 | 文章底部只有「下一篇」和「订阅」 |

长相是「纸张感 / 阅读优先」：暖白纸底、衬线正文、朱红只用来标「发现」，像校勘批注。全部走 CSS 变量，深色模式跟随系统。

## 写新文章

在 `src/content/articles/` 放一个 `.md`，文件名就是 URL：

```yaml
---
title: 标题
saves: 一句话结论。列表页、文章顶部、RSS 摘要都用它。
date: 2026-08-24
tags: ["KDE Plasma", "Wayland"]
featured: true # 上首页，一屏一篇
draft: false # true 则完全不出现在任何地方
---
```

`saves` 是必填的，因为「先给结论」这条原则要靠它落地。写不出这一句，通常说明这篇还没想清楚要帮读者省掉什么。

字段名是 `saves`，但页面上显示的标签是「结论」。这不是笔误：写的人需要被追问「这篇到底省了读者什么」，读的人只需要知道「这行是答案」。

### 中文加粗的坑

CommonMark 判定 `**` 有没有开启/闭合资格，看的是它两侧的字符类型。**加粗的两端都不要贴着中文标点**，里面第一个字和最后一个字都是普通文字最稳。

```markdown
**这句加粗会失效。**后面接着写      ← 坏的：闭合星号前是标点、后是汉字
是**「这句也会失效」**。            ← 坏的：开启星号前是汉字、后是引号
**这句加粗正常**。后面接着写        ← 好的
**这句也正常。**                    ← 好的：闭合星号后面是换行
```

失效时**没有任何报错**，构建照样成功，页面上留下一对字面星号，肉眼很容易滑过去。所以不靠自觉，靠 `scripts/check-output.mjs`：构建完扫一遍产物 HTML，正文里出现字面 `**` 就让构建失败。它挂在 `npm run build` 后面，CI 里也跑，所以带星号的文章推不上线。

规则本身不是 bug，是 CommonMark 为「词之间有空格」的文字设计的。详见站上那篇《Markdown 加粗失效不是中文的问题》。

## 发布

配置已经齐了，没有占位符。要注意的只有一条：

> **仓库必须叫 `WeiPengyu407.github.io`。**

因为 `astro.config.mjs` 里的 `site` 是按 GitHub Pages 用户站配的（站点在域名根）。
如果仓库取了别的名字，站点会落在 `/<仓库名>/` 子路径下，必须同时补 `base`。
漏了 `base` 的表现特别坑：**首页看着完全正常，但样式和所有文章链接全部 404**，
因为首页的相对路径恰好能撞对。

已落实：`site` 指向用户站、GitHub 链接指向 `WeiPengyu407`、邮箱已填。
`PROJECTS` 里除 music-unlock 外 `href` 都是空的，这是最终状态而不是待填项——
其余项目只在本机跑，没有公开仓库。空 `href` 会渲染成纯文本，不会产生死链。

### 别把编的东西当实测发出去

这个站的立身之本是「每篇都是自己踩完才写的」，所以正文里的命令输出、版本号、耗时都必须是
真跑出来的。已经栽过一次：初稿里的示例输出、文章日期、排查耗时全是编的，读起来和实测
一模一样，构建也不会报错。

写完自查两条：**数字有没有出处？命令有没有真跑过？** 拿不准就写「我没验过」，
那比编一个具体值可信。

## 结构

```
src/
  site.ts                    全站文案，改字不用翻组件
  styles/global.css          设计系统（色板 / 字阶 / 行宽 / 动效曲线）
  layouts/Base.astro         壳 + 滚动淡入 + 导航收起
  pages/index.astro          首页五块
  pages/articles/            归档页 + 文章页
  pages/rss.xml.ts           RSS
  content/articles/*.md      文章
```
